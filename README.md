Como usar: 

1 - Clonar o repositorio para seu computador

2 - Por default, o projeto será iniciado no subsistema com o nome do repositorio (falha minha), vá em configurações -> 'configurar projetos de inicialização'
![image](https://github.com/user-attachments/assets/40b198d5-312c-4f0b-8afb-d368c739da42)

3 - mude para 'ModuloDeConsoleCRUD-AED3'
![image](https://github.com/user-attachments/assets/3dfb5190-f5dc-4c79-ae1e-fc19a9e77a3b)

4 - com isso o sistema iniciará com o console utilizando o 'program.cs' como main

5 - caso seja a primeira inicialização, importe o CSV utilizando a opção 1 na janela de seleção antes do menu, após isso, pode utilizar a opção 2 para proximas execuções
